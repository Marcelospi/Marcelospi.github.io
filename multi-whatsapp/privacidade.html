Política de Privacidade

Última atualização: 9 de outubro de 2026

Quem somos

O Multi WhatsApp é um aplicativo desenvolvido por Marcelo para uso interno. Contato: marcelo.spi01@gmail.com.

Dados que acessamos

Quando você autoriza o acesso à sua Conta do Google, o aplicativo pode acessar:

  • Informações básicas da conta (nome e e-mail), para identificar quem está conectado;
  • Suas listas e tarefas do Google Tarefas, para criar, ler e atualizar tarefas ligadas aos atendimentos;
  • Arquivos do Google Drive, para salvar e abrir arquivos usados nos atendimentos;
  • Eventos do Google Agenda, quando você autorizar, para agendar compromissos ligados aos atendimentos.

O aplicativo também usa serviços do Google Maps para mostrar mapas, localizar endereços e calcular rotas. Para isso, os endereços consultados são enviados à Google Maps Platform, conforme os termos da Google Maps Platform.

Como usamos os dados

Os dados são usados apenas para oferecer as funções do aplicativo. Eles ficam armazenados localmente no computador onde o aplicativo está instalado.

Compartilhamento

Não vendemos, alugamos nem compartilhamos seus dados com terceiros.

Uso de dados do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar o acesso

Você pode remover o acesso do aplicativo a qualquer momento em myaccount.google.com/permissions.

Exclusão de dados

Para pedir a exclusão dos seus dados, escreva para marcelo.spi01@gmail.com.
